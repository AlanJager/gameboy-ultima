# 挂起后的系统画面

## 目的

按一个快捷键，游戏停在当前这一步，画面换成模拟器自己的系统。在这一页里恢复游戏，也可以改联机、速度、金手指和画面。恢复之后从停下的指令继续，游戏看不出中间离开过。

这是桌面程序里的一页，不是 GBA 的 BIOS，也不往游戏的显存里画。

## 已经定下的

- 模拟停住时，寄存器、内存、回退记录和联机房间都留着。
- 系统里的无线就是现在的联机房间和中继，不新做网卡。
- 不做 GameCube 联机。
- 第一版是一整页，不在冻住的游戏画面上盖面板，也不做图标主页。

## 挂起和恢复

工作线程里已有的 `paused` 继续负责停机。`paused` 为真时不再调用 `step_quiet`，所以停在一批指令的边界上，不是半条指令中间。声音不再产出新样本，和现在按空格暂停一样。暂停期间联机服务照旧转，房间不会因为打开系统而拆掉。

系统页开着，就一定是暂停。两种进入方式：

- 游戏正在跑：快捷键打开系统页，并暂停。
- 已经用空格暂停：快捷键只打开系统页，保持暂停。

离开系统页只有「恢复」。页面上的恢复按钮、再按一次系统键、空格，以及菜单里的「暂停 / 继续」都做这件事：关掉系统页，并继续游戏。系统页开着的时候，不存在「页面还在、游戏已经在跑」的状态。

没有载入卡带时，系统键不起作用。换卡、复位、读档会关掉系统页，沿用这些操作现在的暂停规则。

回退记录不因为打开系统而清掉。系统页开着时不记录新的回退点，因为模拟没有往前走。

## 这一页

游戏画面换成可滚动的一页，标题是「系统」。载入了卡带时，副标题用卡带名。

页上只有这些，都调用现在已经有的命令：

| 区块 | 内容 |
| --- | --- |
| 恢复 | 一个按钮，离开系统页并继续 |
| 联机 | 现在联机面板里的名字、座位、做主机、经中继开房、本机中继、断开、附近主机、手动加入 |
| 速度 | 现有的 1、2、3、4、5、8 档 |
| 金手指 | 现有的列表、开关、添加、删除 |
| 画面 | 液晶余辉、色彩校正、画面震动 |

放大方式留在「视图」菜单。音量、BIOS、即时存档留在菜单栏。系统页打开时，联机面板、金手指面板和键位面板关掉，避免两层叠在一起。菜单栏的入口还在，它们改的是同一份状态。

## 快捷键

新增可改绑的热键「系统」，默认 `f7`。`f5`、`f6`、`f8` 和 `tab` 已经占用。`escape` 不能作为键位保存，所以不用它做默认。

键位按名字写在现有的绑定表里。旧的键位文件没有「系统」这一项时，用默认的 `f7`。键位设置页里能看到，也能改。

系统页里正在输入名字或金手指时，这一次按键交给输入框。输入框没有焦点时，`f7` 用来离开系统页。

## 文件

- `src/bin/controls.rs`：热键「系统」，以及旧键位文件缺这一项时仍得到 `f7` 的测试。
- `src/bin/system.rs`：这一页的布局。状态变化收成一个纯函数，测试打开、恢复、以及空格暂停之后再打开。
- `src/bin/gpui.rs`：接热键、暂停标志和这一页。不把布局再写进这个文件。
- `README.md`：桌面 App 表加上系统这一行。说明是快捷键暂停后进入，可恢复，并可改联机、速度、金手指和画面。「还没有」里拿掉 GameCube 联机。

## 测试

- 旧键位 JSON 不含系统键时，读出来仍是 `f7`，其它热键不变。
- 纯函数：打开系统页会变成「开着且暂停」；恢复变成「关着且在跑」；已经暂停时打开，仍是暂停。
- `cargo test --offline --bin gameboy-ultima-gpui` 里现有的键位测试继续通过。

界面靠打包后的 `target/ULTIMA.app` 看：游戏停住、这一页盖住画面、恢复后从原地继续。这不是网页，不用浏览器。
