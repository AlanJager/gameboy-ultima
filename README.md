# gameboy-ultima

这个仓库是一台 Game Boy Advance 模拟器，用来学习怎么写模拟器。

## 功能

### 核心

| 功能 | 说明 |
| --- | --- |
| ARM 与 Thumb 解释执行 | 含条件码、IRQ 和未定义指令 |
| 动态重编译 | Apple Silicon 和 x86_64 上，把 Thumb 里连续的低位寄存器运算译成宿主指令。访存、跳转、高位寄存器和 ARM 仍逐条解释。每条的等待和空闲照原拍数累加，定时器和画面对齐。其它机器仍用解释器 |
| 用户与系统共用一组寄存器 | 管理、IRQ、中止、未定义各有 SP、LR、SPSR；FIQ 另有 `r8`–`r14` |
| 板载内存、卡带等待和预取；四路 DMA、四路定时器、按键 | 跟画面共用周期 |
| 背景模式 0–5，精灵、旋转缩放、窗口、混合、马赛克 | |
| SRAM、Flash（64 KiB / 128 KiB）和 EEPROM 存档 | |
| 卡带 RTC | S-3511。写入日期后按真实时间走，记在卡带旁边的 `.rtc` |
| 陀螺仪 | 瓦里奥制造 Twisted（`RZWJ`、`RZWE`、`RZWP`）。静止读数 `0x700`。按住 `[` 向左转，`]` 向右转，松开回到静止。不占用十字键 |
| 倾斜 | 耀西万有引力（`KYGJ`、`KYGE`、`KYGP`）。挂在 `0x0E008000`，写 `0x55` 再写 `0xAA` 才锁存。静止 `0x3A0`。`,` `.` 左右，`;` `'` 上下，松开回到静止。不占用十字键 |
| 太阳能 | 我们的太阳 1、2 和逆袭的萨巴塔（`U3IJ`、`U3IE`、`U3IP`、`U32J`、`U32E`、`U32P`、`U33J`）。和时钟共用 GPIO。0 是全黑，255 是最亮，默认 128。画面右下角点选强度，按卡带记住 |
| 震动 | 瓦里奥制造 Twisted（`RZWJ`、`RZWE`、`RZWP`）和钻头娃娃（`V49J`、`V49E`、`V49P`）。GPIO bit 3 作为输出拉高时马达转。视图里的「画面震动」开着就把这一帧挪开几个像素，默认开，按卡带记住 |

### 声音

| 功能 | 说明 |
| --- | --- |
| 两路方波、一路波形、一路噪声，以及两路 Direct Sound | |
| 按 `SOUNDBIAS` 做 PWM 采样 | 样本进环形缓冲，播放在另一条线程 |
| 1× 时按环里的积压拉长或缩短这一帧的等待 | （`audio_pace`，大约在 0.92–1.08）；环满了仍丢掉新样本 |
| 速度高于 1× 时按倍数抽掉采样 | 喇叭仍按原来的采样率播放，所以听得见而且更快。刚加速时清掉已经进环的旧样本 |

### BIOS HLE

没有放进任天堂的 BIOS。认得出的软件中断在调用处做完，模式不变；认不出的进入向量 `0x08`。这条快路径默认开着，菜单里可以关掉，关掉后已实现的调用也走向量。向量上是一小段 `movs pc, lr`，用来返回。

| 功能 | 说明 |
| --- | --- |
| 软复位、寄存器复位、硬复位、Halt、Stop、IntrWait、VBlankIntrWait、CustomHalt | |
| 除法、开方、反正切；CpuSet / CpuFastSet | |
| 位展开、LZ77、哈夫曼、游程、差分；背景和精灵的仿射参数 | |
| `0x0D` | 把 `r0` 设成 `0xBAAE187F` |
| SoundBias | 把偏置收到 0 或 `0x200` |
| MidiKey2Freq（`0x1F`） | 按波形频率、音高和微调算出定时器频率 |
| 音乐序列器 | `0x1A` 初始化工作区并写到 `0x03007FF0`，`0x1B` 改混音模式。每帧 `0x1D` 重开 FIFO DMA，`0x1C` 按 MP2k 轨道推进一步并混进 PCM。`0x1E` 清声部。`0x20`–`0x24` 是打开、开播、暂停、继续、淡出。`0x28` / `0x29` 开关垂直同步。`0x2A` 写下 36 个指针，都指向 `0x188` 的 `bx lr` |
| MultiBoot（`0x25`） | 没有另一台机器，`r0` 返回 1 |

### 联机

| 功能 | 说明 |
| --- | --- |
| 多人线缆模式 | 最多 4 台，一次交换四路 16 位。没插线时到点自己结束，空位是 `0xFFFF` |
| e-Reader 卡 | 菜单「载入 e-Reader 卡」读已经解开的 `.bin`。2112 字节时跳过前 114 字节的头，也可以只给 1998 字节内容。没插线时占 2 号位，按超级马力欧 Advance 4 的多人联机步骤把卡送进去。正在联机时让给真的线。不扫描实体卡，也不带 e-Reader 启动卡带。`.raw` 要先解开成 `.bin` |
| 局域网发现 | 主机听 TCP `5576`，并往局域网 UDP 广播；可以点搜到的主机，也可以手填地址。卡带内容不一致会拒绝 |
| 跨网中继 | 一台先开「本机中继」（TCP `5578`）。主机点「经中继开房」，把状态栏里的 `地址#房间号` 发给对方，填进手动加入。两边都是向外连接。局域网发现和手填地址照旧 |
| 名字和座位 | 主机是 1 号机。人少的时候面板留四个位子，联合房间人多了再往下排 |
| 无线适配器走 32 位普通模式 | 登录按 `NINTENDO` 和 `0x8001` 对完，再用 `0x9966` 命令做广播、目录、连接和数据。电波经同一个房间转发。没进房间时适配器还在，只是看不到别人 |
| 联合房间 | 同一间最多 16 台。`0x11` 按已经连上的客户返回信号，空位是 0。广播目录一次最多交出 4 台，再问能看到后面的。线缆对战仍是前 4 台 |
| 同一台 Mac 上再开一台 | `open -n target/ULTIMA.app`，用加入连到已经在听 `5576` 的那台 |

### 桌面 App

要跑的程序是 `gameboy-ultima-gpui`。

| 功能 | 说明 |
| --- | --- |
| GPUI 窗口 | 模拟在另一条线程里出帧和采样 |
| 图库 | 记下载入过的 `.gba`（不复制卡带文件）。没有自选封面时，大约 30 帧后用当时的画面做封面，也可以另选 PNG 或 JPEG |
| 速度 | 1、2、3、4、5、8 倍；按住加速默认 4 倍，按住时取锁定速度和加速档里更高的一档 |
| 键盘可以改键 | 手柄用 gilrs：东面键 A，南面键 B，Select / Start，十字键和左摇杆，左右扳机是 R / L |
| 按卡带记住 | 速度、加速档、键位、BIOS、放大方式和液晶选项写在 `cart_prefs/`。没有这张卡带自己的文件时，用全局键位和 `shell.json` |
| 即时存档 | 三个槽加一份快速档，按卡带内容分开，写在应用数据目录的 `save_states/`。游戏自己的 `.sav` 仍写在卡带旁边，换卡或退出时如果改过就写回 |
| 回退 | 按住回退键往回走大约两分钟。每半秒记一档，不复制卡带。松手后从停下的地方继续。换卡、复位或读档会清掉 |
| 金手指 | CodeBreaker（明文，以及 `9` 开头的加密）、GameShark v1，和 GameShark / Action Replay v3。v3 用另一把钥匙，能写内存、做加减和间接写入，也能按条件跳过或走另一支。改卡带的补丁盖在读取上，关掉这条码就回到原来的半字。按键码跟着这条金手指的开关，每帧写一次。输入时按一行一条排好，列表里写出这条码会改的地址和数值。减速，以及会关掉别的码的条件，还没做。按卡带记在应用数据的 `cheats/` |
| 暂停、复位、音量、静音、联机面板 | |
| 系统 | 默认 F7，可在键位里改。游戏停在当前这一步，画面换成系统页。可以恢复，也可以改联机、速度、金手指，以及液晶余辉、色彩校正和画面震动。寄存器、内存、回退记录和联机房间都留着 |
| 调试 | 系统页里打开，只在暂停时改。能看当前这一条附近的指令，点一行设断点，看 32 字节内存，以及方波、波形、噪声现在的音量。断点命中后停进系统页，这一条还没执行。游戏跑着的时候不改这些 |
| 画面 | 各平台有 CPU 整数最近邻和线性放大；macOS 另有 Metal 最近邻和锐化，也可以并排对比。液晶余辉把上一帧和这一帧各取一半，静止时画面不变；色彩校正用公开的 GBA 液晶矩阵。这两项默认关，做在放大之前，封面仍用原始画面 |

## 跑起来

安装 Rust 之后：

```sh
cargo run --release --bin gameboy-ultima-gpui
cargo run --release --bin gameboy-ultima-gpui -- 卡带.gba
```

不带路径时打开图库。应用数据里有 `library.json`、封面、即时存档、键位、`cart_prefs/`、`shell.json`。macOS 在 `~/Library/Application Support/gameboy-ultima`，Windows 在 `%APPDATA%\gameboy-ultima`，Linux 在 `$XDG_CONFIG_HOME/gameboy-ultima`，没设这个变量时在 `~/.config/gameboy-ultima`。

Windows 和 Linux 用上面的 `cargo run`。画面默认是 CPU 整数最近邻，没有 Metal。x86_64 上会走动态重编译，别的指令集仍逐条解释。还没有 Windows 或 Linux 的安装包。

macOS 可以打成独立应用，构建需要 Xcode Command Line Tools：

```sh
./scripts/package-macos.sh
```

产物是 `target/ULTIMA.app`。

默认按键：方向键是十字键，X / Z 是 A / B，A / S 是 L / R，Enter 是 Start，Backspace 是 Select，R 复位，Space 暂停。F5 快速存档，F8 快速读档，Tab 按住加速，F6 按住回退，`[` / `]` 是陀螺仪，`,` / `.` / `;` / `'` 是倾斜的左右上下。这些都可以在键位设置里改。

## 测试

```sh
cargo test
```

`data/arm` 和 `data/thumb` 是单条指令的初态和终态。`roms/` 里的 `arm.gba`、`thumb.gba`、`memory.gba` 来自 [jsmolka/gba-tests](https://github.com/jsmolka/gba-tests)，许可证是 MIT，用来检查 CPU 和内存。`roms/sensors.gba` 是传感器实验卡，游戏代码 `ULTS`。左边的陀螺仪跟着 `[` `]` 往两侧倒，中间的小球跟着 `,` `.` `;` `'` 在槽里滚，右边的太阳跟着右下角的日光变大。`roms/rumble.gba` 是震动实验卡，游戏代码 `V49J`。靶心画死在画面上，马达每隔大约四分之一秒转一下；视图里的「画面震动」开着时整幅画面跟着晃，左上角的灯同时变亮。
